Action buttons

Page and document actions: Edit, Copy link, Copy, Download, Print, and Reset. They are icon-only and btn-sm, with aria-label and title. Reset keeps its text because it clears what the person entered. The markup comes from _includes/action-buttons.html and the behavior from public/js/action-buttons.js. In the real include, the Nunjucks variables actionsContentId, actionsFileName, actionsEditHref, actionsPrintHref and actionsResetHref fill the attributes shown here.

The full set

Copy and Download are menus. Try each item: a check shows in the button for 2 seconds, and a hidden live region announces it.

When a format does not apply

The script leaves out formats that need a document when the page has none, turns a menu with one format into a single button, and removes a menu with none. This bar has no document, so Copy is gone, and Download shows only the CSV a site registered for its table.

Messages

Instant actions show a check and an announcement. A failure shows a toast with text. A long action is disabled with a spinner while it runs, then a toast says what happened.

Sizes

One size per group. Page actions are btn-sm; a form footer is the default size. The small button has the smaller shadow.
