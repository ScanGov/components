Accordion

Bootstrap's accordion, powered by the Collapse component already vendored sitewide (bootstrap-trimmed.min.js, loaded in every page via _includes/js.html) — using it adds no new JS weight. Each .accordion-button / .accordion-collapse pair needs a unique ID; two accordions on the same page can't share one. Used for a chart's accessible data table in _includes/report-chart.html — not native <details>/<summary>, for a consistent look with the rest of the site's interactive components.
